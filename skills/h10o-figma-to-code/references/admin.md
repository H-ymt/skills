# 管理画面

管理画面を触るときだけ読む。公開画面の見た目（`visual.md`）は読まない。

管理画面は、そのシステムの標準 UI に合わせる。独自の見出し、フォント、ページ全体の最大幅を足さない。細かいところは標準の部品で無理なく作れる形にする。

余白、角丸、影の独自トークンは置かない。標準 UI の値を使う。すでにある独自トークンは、ほかの画面で使っていても、同じ変更で標準 UI の値に替えて削除する。状態の色は、標準 UI に状態の色があればそれを使う。無いときだけ管理画面のスタイルに置き、公開サイトのプリミティブを参照してよい。公開サイトの色の正本には足さない。状態の色は、意味がひと目で分かる強さを保つ。

本文の無いデータに、本文用のキャンバスを付けない。機能は見た目の層に書かない。関連する設定は1画面でまとめて見えるようにする。カードの幅は枠ごと揃え、右側だけが空く見え方にしない。公開状態は、公開に関わる設定を1つのまとまりに置き、今の状態を表示してひと目で分かるようにする。一覧では各行に状態を出す。

新しく書く文言は、よく使われる言い方で、今の種類だけに閉じない名前にする。
